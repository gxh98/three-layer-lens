# 三层模型核心参考（method-core）

> 何时读我：需要校准分析角度、确认某个打法属于哪层、或给不出具体案例时。
> 来源：薛辉本人 2026 三层人群模型（得到大脑 KB QJmPl9r0）。

## 一、三层判断标准（怎么快速定层）

拿到一个打法，用下面三个问题定位：

| 问题 | 是 → | 否 → |
|---|---|---|
| 这句话讲的是产品本身的属性吗（材质、工艺、参数、价格）？ | 🔴 刚需层 | 往下问 |
| 这句话讲的是产品能解决的具体使用场景吗？ | 🟡 影响层 | 往下问 |
| 这句话讲的是人为什么需要这个场景背后的动机（身份、关系、恐惧、向往）？ | 🟢 潜在层 | 还没打到位 |

**一句话口诀**：讲产品 → 讲场景 → 讲人。

## 二、经典案例对照表

| 行业 | 🔴 刚需层打法 | 🟡 影响层打法 | 🟢 潜在层打法 |
|---|---|---|---|
| 钢琴 | 音色好、教学专业、考级通过率 | 孩子学琴能有一技之长 | "学钢琴的孩子不会变坏" |
| 白酒 | 口感绵柔、纯粮酿造 | 聚会喝、送礼有面子 | "你为这个家付出了多少" |
| 少儿篮球 | 专业教练、帮助长高 | 孩子放学有地方去、能锻炼身体 | "培养敢拼敢抢的性格，被撞倒了不哭" |
| 奔驰 | 发动机排量、配置参数 | 商务接待够体面 | 身份彰显 |
| 编导培训 | 学剪辑、学脚本、学拍摄 | 能进影视公司上班 | 进入一个有发展的行业挣钱（竞品是外卖） |
| 医美 | 变美、技术好、安全 | 改善外貌焦虑 | 改变运气/人生（竞品是风水） |
| 理发 | 剪得好看、技术好 | 换个发型换个心情 | 形象改造、身份认同 |
| 二手车 | 车况好、价格低 | 代步够用 | 便宜又有面子 |

## 三、潜在层竞品（最容易讲错的概念）

潜在层的竞争对手**不是同行**，是跟你抢同一批人时间的所有东西。

- 编导培训的竞品：外卖、网约车（同样是"没学历也能挣钱"的选项）
- 医美的竞品：风水、算命（同样是"改运"的选项）
- 钢琴培训的竞品：任何一个让孩子"不变坏"的方案

**用法**：找潜在层角度时，先问"这个人在没有我这个品类的情况下，会拿什么来解决同一个深层焦虑？"答案就是竞品，也是潜在层选题的切入口。

## 四、四条关键认知（展开版）

**1. 不分层就谈目标群体，谈的往往只是刚需层**
大多数老板说"我的目标客户是 25-35 岁女性"，其实描述的是已经要买的人。真正的大盘在还没决定要买的人那里。

**2. 小众赛道 + 大人群潜在层 = 大钱**
刚需层赛道再大也是窄的（白背心的天花板就在那儿）。赛道小不要紧，潜在层的人群基数大就行。

**3. 行业是纵向的，营销是横向的**
行业是一个纵向的深井，营销是横切过去的一个层。会搞流量的人，换行业照样能活；只会行业手艺的人，行业一冷就吃不上饭。挣钱的安全感来自会搞流量，不来自待在哪个行业。

**4. 媒体是手段，营销是需求**
不要把做内容当成做媒体。内容的目的是把需求讲出来，不是把播放量做上去。

## 五、八大爆款元素与三层的配合

八大元素是"怎么打"，三层是"打谁"。**先定层，再选元素**，顺序不能反。

| 元素 | 更适合的层 | 说明 |
|---|---|---|
| 成本 | 🔴 刚需 / 🟡 影响 | 便宜、划算，直接刺激已需求人群 |
| 人群 | 🟡 影响 | 圈定某类人，扩大触达 |
| 猎奇 | 🟢 潜在 | 用意外感打断无需求状态 |
| 荷尔蒙 | 🟢 潜在 | 本能驱动，跨品类有效 |
| 反差 | 🟢 潜在 | 打破既有认知，制造记忆点 |
| 头牌 | 🟡 影响 | 权威背书，降低决策成本 |
| 怀旧 | 🟢 潜在 | 情绪唤醒，与品类无关 |
| 最差 | 🟢 潜在 | 极端对比，制造话题 |

## 六、常见误判（自检用）

- **把影响层当潜在层**：讲了场景但没讲动机，只是把刚需层写长了
- **把潜在层讲成鸡汤**：只有情绪没有具体人群，落不了地
- **三层写成同一批人**：说明根本没分层，只是换了个说法
- **潜在层选题无法转化**：流量大但接不住，缺少从潜在层到影响层的承接路径
