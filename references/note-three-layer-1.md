# 薛辉：选题三层——做生意先分析目标群体？先分清潜在层、影响层、刚需层

> 来源：得到大脑笔记，2026-11-21 创建
> 笔记 ID：1927596332281771632

## 为什么"先分析目标群体"是错的？

因为"目标群体"本身**分三层**，不分层就谈目标群体，谈的往往只是**刚需层**。
- **三层划分**：**潜在层**、**影响层**、**刚需层**。
- **核心追问**：一个老板到底属于哪一层？**不知道**，就说明"目标群体"这个词没用。
- **选题差异**：打**刚需层**的选题、打**潜在层**的选题、打**影响层**的选题，**完全不一样**。

## 打不同层，赚的钱差多少？

打**刚需层**挣的是**小钱**，打**潜在层**才可能挣**大钱**。
- **经典案例**：日本知名钢琴广告语"**学钢琴的孩子不会变坏**"，打的是**潜在层**——妈妈不一定让孩子学钢琴，但**希望孩子不变坏**，不变坏就成了学钢琴的目标群体。
- **刚需层的天花板**：刚需层一开始**一定小**，做大了也**竞争激烈**，比如**白背心**的刚需，但白背心竞争激烈。
- **小众赛道的机会**：钢琴这种**小众赛道**，提**大人群潜在层**，就是**大钱**。
- **结论**：只分析**刚需层**的目标群体，就是挣**第一波小钱**，**永远挣小钱**。

## 为什么要把外卖员、滴滴司机当目标？

因为**外卖和滴滴跟短视频是竞争对手**，抢的是同一批人的时间。
- **反向选题**：每天想的是怎么让**送外卖的人**和**跑滴滴的人**来关注，因为他们是**竞争对手**。
- **反面教材**：如果目标群体只是"**想学短视频的人**"，那不好意思，你只是**一个小老板**，做不了**大生意**。
- **学员画像**：各行各业的**二手房中介**，只是想**转型进短视频**。

## 短视频对不同人意味着什么？

短视频编导正在变成**像工程师一样的刚需岗**。
- **典型画像**：**大学毕业即失业**的人，把编导当作**再读一次脱产**的学科，作为**就业的跳板**。
- **岗位属性**：短视频是**很有需求的岗位**、**刚需岗**，类似**当年的计算机工程师**。
- **类比**：像**北大青鸟**一样，学短视频**可能创造一个短视频的上市公司**。
- **对照**：别人还在卖**9块9**的时候，已经有人在**做学校**了。

## 挣钱的安全感到底来自哪？

来自**你会搞流量**，而不是来自你在**哪个行业**。
- **行业会倒**：房地产行业**可能会倒**，IT行业、游戏行业**各行业都有可能倒**。
- **营销是横向的**：行业是**纵向**的，营销是**横向的一个层**，营销是一个**环**。
- **判断句**：会搞营销，就**不会吃不起饭**；**媒体是手段，营销是需求**。
- **工种类比**：每个公司都需要一个**财务**，每个公司也都需要一个**新媒体营销人才**，这是**基础的刚需工种**——哪个公司不需要**搞流量**？
- **试错逻辑**：年轻人不知道人生方向、想多试但**适合成本很高**时，可以用**短视频编导逻辑**去试各行各业，就像**加入哪家 coding 不是 coding**。

## 补充细节
- **"刚需层一定小"的口径**：原文说的是刚需层**一开始**一定小，做大后则是**竞争激烈**，两层原因分开讲。
- **"竞争对手"的指代**：外卖、滴滴被称为竞争对手，指的是**争夺同一批用户的时间**，不是业务上的直接竞争。
- **"北大青鸟"的用法**：原文是拿它类比**技能培训做成规模化生意**，并说"学辉可能可以创造一个短视频的上市公司"。
